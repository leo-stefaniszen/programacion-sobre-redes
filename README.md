# Trabajos Prácticos - Programación Sobre Redes

Repositorio destinado al desarrollo y entrega de los distintos Trabajos Prácticos realizados durante la cursada.

## Tecnologías Utilizadas

Dependiendo del trabajo práctico, pueden utilizarse:

* Java
* Maven
* Serialización binaria
* JSON
* Colecciones
* Archivos
* Consola ANSI
* Programación Orientada a Objetos

## Estructura General

La organización de carpetas puede variar según los requerimientos de cada trabajo práctico.

```text
src/
└── main/
    └── java/
```

## Compilación

Los proyectos Maven pueden compilarse mediante:

```bash
mvn clean compile
```

## Ejecución

La forma de ejecución depende del trabajo práctico contenido en la branch correspondiente.

## Convención de Branches

* `main`: versión estable.
* `develop`: integración de cambios.
* `feature/*`: funcionalidades específicas.
* Otras ramas pueden utilizarse para prácticas, pruebas o entregas.
